## GRUPO 13 - PetChain

### O que foi criado? 
O PetChain é uma plataforma para registrar ocorrências de resgate animal, acompanhar cada etapa do atendimento e visualizar indicadores em um dashboard com mapeamento geográfico.

### Quem vai utilizar? 
Será utilizado por ONGs, protetores independentes, voluntários e instituições envolvidas no resgate e acolhimento de animais.

### Como será usado? 
A ferramenta permitirá registrar ocorrências, definir prioridades, atribuir responsáveis e acompanhar o andamento dos resgates até sua conclusão. Os dados registrados serão utilizados para identificar atrasos, ocorrências pendentes e regiões com maior demanda, contribuindo para uma atuação mais organizada e eficiente.
